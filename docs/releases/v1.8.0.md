# v1.8.0 — 多言語対応・読解／執筆機能・設定画面の刷新

Mouse Dictionary for Karakeep and Anki の設定画面を刷新し、日本語・英語の切り替えに対応しました。Karakeepの記事を読むためのReaderと、自分の文章を推敲するWriterも追加しています。

## 多言語対応

- 設定の先頭で日本語／英語を選択できます。初期値は日本語で、変更は自動保存されます。
- 設定・Reader・読解履歴・Writerの画面と、新しく生成するAI講評、音声入力の認識言語が切り替わります。
- 画面文言とAIプロンプトを `src/i18n/locales/ja/translation.json` と `en/translation.json` で管理します。言語追加の手順も同梱しました。
- AI講評のキャッシュを言語別に分け、別言語の講評が新しいレビューに混ざることを防ぎます。

## 設定画面とデザイン

- Material 3の役割別配色を使い、白・グレー・黒の濃淡で統一しました。
- 選択中・ホバー・押下・キーボードフォーカスを見分けられるよう調整しました。選択欄の下矢印もグレーに統一しています。
- お試し用テキストと辞書プレビューを専用枠に配置し、目次と重ならないよう修正しました。大きな表示サイズは枠内でスクロールできます。
- ヘッダーを「Mouse Dictionary for Karakeep and Anki」に変更し、本の図柄を使わないM／Dモノグラムとファビコンを追加しました。
- バージョン番号からこのGitHubリポジトリを開けます。

## Karakeep Reader

- Karakeepの記事を専用タブで読み、速度調整・文単位の移動・再読マークを利用できます。
- 英文を端末内のUDPipeで解析し、係り受け・語の役割・辞書の訳候補を表示します。
- 文字または音声で答えて、AIによる要点別の読解レビューを受けられます。回答と講評は履歴から確認できます。
- 読書位置を端末に保存し、Karakeep 0.33.2の読書位置との同期に対応しました。
- 単語・穴埋めカードのAnki `.apkg` 作成、Karakeepでのマーカー登録、タイムスタンプ付き動画文字起こしの整形に対応しました。

## Writer

- 文書の作成、Markdown／テキストの読み込み、Markdownの書き出しに対応しました。
- AIが問題箇所・理由・問いを提示します。書き換え案の代筆は行いません。
- ローカルの文章チェック、観点別レビュー、版の保存・差分・比較、レビュー方式の比較を利用できます。

## 設定と保存

- OpenAIのAPIキーとレビュー用モデルを設定画面で管理できます。APIキーはブラウザーの拡張機能用ローカルストレージに保存し、設定同期とJSON書き出しから除外します。
- 既存の設定は引き継ぎます。保存済みの記事・原稿・辞書本文・AI講評の内容は自動翻訳しません。

## ダウンロードと導入

- Chrome: `mouse-dictionary-chrome-1.8.0.zip`
- Firefox: `mouse-dictionary-firefox-1.8.0.zip`

ChromeではZIPを展開し、`chrome://extensions` でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から展開先を選択してください。すでに開発版を導入している場合は、拡張機能を再読み込みしてください。

Firefox用ZIPは署名済みのストア配布版ではありません。動作確認には `about:debugging` の「このFirefox」から「一時的なアドオンを読み込む」を使用してください。Firefoxでの実機動作確認は未実施です。
